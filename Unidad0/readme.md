En esta unidad se trabajó con la guía de estilo PEP8, que establece recomendaciones para escribir código Python de forma clara, ordenada, legible y fácil de mantener. Se aplicaron normas relacionadas con la indentación, nombres de variables y métodos, espacios, longitud de líneas, comentarios y organizacion del código.

También se trabajó con Docstrings, utilizados para documentar funciones, métodos y clases, facilitando la comprensión y mantenimiento del código.

Además, se introdujeron conceptos relacionados con el Heap, como parte de los fundamentos necesarios para comprender la organización y manejo de datos en programación.

Los ejercicios y ejemplos practicados durante la clase se encuentran en sus respectivas carpetas organizadas.
