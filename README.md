# 📚 INF-220 | Estructuras de Datos I

Repositorio personal de estudiante para la materia **Estructuras de Datos I (INF-220)**.

Este repositorio contiene apuntes, ejemplos y ejercicios desarrollados durante el curso, organizados por unidades.

## 🎯 Objetivo

Utilizar este repositorio como espacio de aprendizaje y seguimiento de las actividades realizadas en la materia, aplicando buenas prácticas de programación y organización del código.

## 📂 Contenido

| Unidad       | Contenido                                     |
| ------------ | --------------------------------------------- |
| **Unidad 0** | Estándares y buenas prácticas de codificación |
| **Unidad 1** | Modelos de representación de datos            |
