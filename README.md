# 📚 INF-220 | Estructuras de Datos I

Repositorio personal de estudiante para la materia **Estructuras de Datos I (INF-220)**.

Este repositorio contiene apuntes, ejemplos, ejercicios y simulaciones desarrollados durante el curso, organizados por unidades temáticas y aplicando el estándar de codificación **PEP 8**.

---

## 🎯 Objetivo

Utilizar este repositorio como espacio de aprendizaje, práctica y seguimiento de las actividades realizadas en la materia, aplicando buenas prácticas de programación, arquitectura limpia y organización modular del código.

---

## 📂 Contenido del repositorio

| Carpeta | Tema |
| :--- | :--- |
| **Unidad0** | Estándares de codificación y buenas prácticas (PEP 8) |
| **Unidad1** | Ejercicios base de estructuras de datos (Niveles A, B y C) |
| **Unidad2** | TAD Polinomio (patrón MVC) |
| **Unidad3** | Listas enlazadas simples |
| **INDEX** | Simulaciones de indexación en Arreglos, Listas Enlazadas, Pilas y Colas |
